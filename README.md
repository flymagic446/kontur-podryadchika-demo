# УНЕТ — демонстрация интерфейса

Адаптивный интерфейс с тремя режимами просмотра. Список заданий, редактирование таблиц, обезличенные формы документов, сообщения и вложения.

Данные примеров вымышленные и хранятся в браузере посетителя.

Публикация: GitHub Settings → Pages → Deploy from a branch → main → / (root).
